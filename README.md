# 🚀 About Me

I enjoy solving engineering problems that live beneath the UI.

Whether it's a healthcare claim that **must validate correctly**, an analytics dashboard processing **millions of records**, or an AI assistant expected to return the **right medical code**, I enjoy building systems people trust.

Over the last **5+ years**, I've worked across **Healthcare, ERP, FinTech and E-commerce**, building products from frontend to backend while collaborating closely with product teams and backend engineers.

Recently my focus has shifted toward **Applied AI**, where I'm building production **RAG systems** and researching **Machine Unlearning** for my Master's thesis—exploring how user data can truly be removed from LLMs after it has propagated through embeddings, adapters and vector databases.
